# 可视化（成员C 负责）

本目录为系统展示层，消费组长算法产出的 ADS 结果表 / `data/processed/` 结果文件，
**不实现算法逻辑**。

## 目录结构

```
visualization/
├── web_frontend/   # 自研 Streamlit 看板（主交付，可直接运行演示）
└── superset/       # Superset 看板配置（可选方案，数据源与图表规划说明）
```

## 交付物（对应分工文档第 8 节）

1. **6.数据可视化设计**（Word，1 份）：看板原型、图表类型选择、数据源说明、
   交互设计（筛选 / 下钻 / 订阅），含封面与原型截图。
2. **可视化源码/配置**：本目录前端代码（或 Superset 配置导出），附 README 与部署说明。
3. **最终展示页面**：集成区域筛选、容量流量下钻、容量饱和预警订阅入口的可交互界面。

## 快速运行

见 `web_frontend/README.md`。

## 关键口径

- 容量饱和预警（`*_saturation_warnings.csv`）是题目正式功能；
  高吞吐量繁忙度预警（`*_throughput_warnings.csv`）仅辅助参考，不能当作饱和度展示。
- 数据源路径不写死本机绝对路径；后续切 Hive 只替换取数来源，页面逻辑不变。
- 依赖组长 11-08 前产出稳定 ADS 结果表后正式联调；前期可用本地结果样例搭原型。
