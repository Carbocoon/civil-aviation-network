# 测试目录

- `test_metrics.py`：核心算法单元测试（组长维护，20 项，使用合成小图、不依赖真实数据）。
  在**本仓库根目录**（含 `algorithm/` 与 `tests/` 的目录）下运行：
  `python -m unittest discover -s tests -p "test_*.py" -v`
  覆盖：中心性与抽样降级、耦合权重、节点/边瓶颈、两类预警分级、脆弱性 Top-K 语义、
  区域筛选中英文兼容、空图与除零、脏数据加载、自环/孤立航段计数、空表头导出、Hive 占位提示。
- 成员D 的集成测试（功能 / 接口 / 性能 / 兼容）也放在本目录，请**另建文件**，勿覆盖 `test_metrics.py`。
